# bLOK CHaiN

Crypto-flavored chain puzzle. Compile random blocks into one solid chain. Timed ranked play, Top 50, stake $bLOkz, validator chat.

## Dev

```bash
npm install
npm run dev   # http://0.0.0.0:8080
```

## Build

```bash
npm run build
```

Token contract (reference): `contracts/BLOKZ.sol`
